ProxyMind couldn't open the project

Every ProxyMind project needs rules of engagement (what's in scope) before anything can be sent. Create one from the example and load it:

proxymind -p <project> roe use roe.yaml

See examples/roe.yaml. The desktop app opens ~/.proxymind/desktop.pmproj unless you pass a project file or set PROXYMIND_PROJECT. Then restart the app.
