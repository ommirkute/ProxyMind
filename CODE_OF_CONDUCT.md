# Code of Conduct

ProxyMind adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give constructive feedback, and keep discussions focused on the work. Harassment of any kind is not tolerated.

Report unacceptable behavior privately to the maintainers through GitHub (see the repository's profile for contact details). All reports are handled confidentially.

## Project-specific note

ProxyMind is a security tool. Discussions about offensive techniques are welcome when they relate to authorized testing and to improving the tool. Requests for help attacking systems without authorization are not.
